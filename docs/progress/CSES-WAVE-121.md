# CSES 200 expansion: wave to 121

Ten additional official tasks extend the foundation checkpoint from 111 to **121 registered and 121 certified**, with zero partial or failed entries and a hard target of 200. The tasks are Digit Queries (2431), Array Division (1085), Removal Game (1097), Longest Common Subsequence (3403), Josephus Problem I (2162), Concert Tickets (1091), Traffic Lights (1163), Sum of Three Values (1641), Sum of Four Values (1642), and Maximum Subarray Sum II (1644).

These entries use the existing variables, array, and DP renderers. Digit Queries traces the identified digit-length block, Array Division shows each feasibility scan, Removal Game and LCS update interval/prefix DP cells, Josephus marks each removed child, Concert Tickets marks sold positions, Traffic Lights displays the longest gap after each insertion, the sum searches highlight considered values, and the bounded subarray task shows its selected prefix difference. Every task has original learning copy, bounded custom JSON input, a reference snippet, a lazy-loaded route, and a certificate record.

Independent checks cover direct digit concatenation plus cumulative-digit binary search, exhaustive partition cuts, alternating minimax, enumerated common subsequences, direct circular deletion, naive ticket multiset removal, forward gap recomputation, exhaustive triple/quadruple searches with semantic output checks, and exhaustive bounded subarray sums. The example tests also execute each displayed reference snippet and compare it with the trace output. The full CSES 200 release remains gated on 79 more certified tasks and the mandatory security, browser, fresh-clone, CI, and visual checks.
