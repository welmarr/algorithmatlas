No production `TODO`, `FIXME`, `MOCK`, `STUB`, `fake`, `dummy`, `hardcoded`, “coming soon”, or `console.warn` marker was found by a case-insensitive `rg` scan across `apps`, `packages`, `tests`, `docs`, README and SECURITY. The only match was test fixture text `state: { hacked: true }` in `tests/ai.test.ts`, intentionally proving that an extra model field is discarded. ## Unused, dormant, and duplicated concepts

- `packages/domain/src/index.ts` declares `Algorithm`, `AlgorithmVariant`, `AlgorithmImplementation`, `Simulation`, `SimulationRun`, `UserSubmission`, `ExecutionResult`, `AIProvider`, `AIResponse`, `AIConnector`, `ProblemPack`, `Hint`, and `AlternativeAlgorithm`; their declared shapes are not runtime objects in the current app. They should be kept only if the future roadmap adopts them and given implementation/tests at that time.
- 23 `EVENT_TYPES` entries have no bundled producer. Some have reducer cases; many only annotate/focus. A future pack should not treat them as complete without per-event schemas and tests.
- Queue entities/collection state exist in reducer and inspector, but no queue renderer. Stack and heap collection code is dormant. `HEAP_EXTRACT` currently behaves as array pop, which is not a heap extraction contract.
- The domain `AIConnector`/`AIResponse` interfaces and actual `TeacherConnector`/`StepExplanation` in `ai-sdk` duplicate conceptual roles with different shapes. No production adapter connects them.
- There is no superseded executable module or second replay engine. `apps/web/src/app/lab/page.tsx` is a link hub, not dead code. `artifacts/` was empty at inspection; generated `test-results/` is ignored.

## Top five risks

1. **Misleading learning sequence:** one event per teaching step obscures the actual decision and produces inflated step counts.
2. **Code-language contract:** the restricted editor is real but not JavaScript-conformant for scope; broadening without isolation would be unsafe.
3. **Reproducibility and release provenance:** all source is untracked with no commit, remote, or attributable CI run.
4. **Dependency security backlog:** five advisories are present in the locked package graph; reachability requires review.
5. **Protocol/renderer coverage gap:** 23 declared event types lack producers, event payloads are not type-specific, and some visible families overflow mobile.
