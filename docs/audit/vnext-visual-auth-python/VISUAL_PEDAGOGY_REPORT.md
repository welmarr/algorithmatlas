# Visual pedagogy report

A framework-free package maps canonical semantic events and teaching steps into serializable choreography plans. Renderers consume presentation directives without calculating results or modifying canonical state. Phases orient, focus, compare, decide, transform, confirm and settle; manual navigation immediately establishes a readable settled state. Runtime animation is cancellable on seek/run/navigation and respects reduced motion.

Color conveys comparison/read, change and accepted/explored/final roles. Dashed/solid outlines, labels, equations, before/after values and textual reasons carry the same meaning without color. Sorting preserves item identity through actual card movement. Family strategies show two-pointer/window relationships, prefix/Fenwick indices, binary-search intervals, BFS frontier/path, weighted relaxation/minimum queue, tree traversal, DP dependencies, string alignment, backtracking undo, arithmetic and polygon coordinates.

Ten representative views were inspected from real Playwright screenshots: Increasing Array, Sum of Two Values, Labyrinth, Shortest Routes I, Tree Diameter, Dice Combinations, Edit Distance, Factory Machines, Chessboard and Queens and Polygon Area. Automated checks cover these at 390×844, 768×1024, 1280×800 and 1920×1080. No document-level horizontal overflow was found. Swap animations, reduced-motion zero-animation state and stale-phase cancellation are asserted.

Review found and fixed duplicate change badges, a DP dependency color collision, a stale relaxed-edge cue and a misleading queen final label. Canonical immutability/serialization is checked at every teaching step across all 20 curated problems. Browser Python uses this same presentation layer with inferred semantics; it does not receive curated problem-specific claims when intent is unknown.

The full WCAG/manual screen-reader and all-state contrast audit is still open. Static diagrams remain intentional where motion adds no teaching value.
