# CSES catalog report

The source-backed status records **100 unique registered official CSES task IDs and 100 certified entries**, compared with 20 at the pre-milestone SHA. The generated [catalog](../../CSES-CATALOG.md) includes every title, task ID, category, algorithm, renderer and choreography. The exact IDs are also in [status.json](status.json) as `certifiedIds`.

Category counts: Introductory Problems 10; Dynamic Programming 15 and Dynamic Programming 2D 1; Graphs 17 plus Shortest Path 1 and Depth-First Search 1; Range Queries 10 plus Fenwick Tree 1; Trees 10 plus Tree Traversal 1; Mathematics 8; Strings 5; Geometry 3. The remaining entries span sorting/searching, arrays, binary search, two pointers, sliding window, grids, advanced structures and backtracking. Exact Sorting and Searching has 10 entries; related search/array categories broaden that family. This is a documented distribution choice, not a claim that every approximate quota label was met literally.

Reusable families include greedy, sorting, sliding window, two pointers, binary search, prefix sums, 1D/2D/bitmask DP, BFS/DFS, topological order, Dijkstra/Bellman-Ford/Floyd–Warshall, DSU/MST/SCC, Fenwick/segment tree, Euler tour/binary lifting/LCA, KMP/Z/trie, modular arithmetic/combinatorics/number theory, and geometry predicates. Weak areas for the 200 roadmap are exact-category sorting/searching, deeper string variants, advanced geometry, and hard graph/range variants. See [CSES 200 roadmap](../../roadmap/CSES-200.md).
