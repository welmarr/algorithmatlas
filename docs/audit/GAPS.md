# Gaps, technical debt, and deferred work

See [FEATURE_MATRIX.md](FEATURE_MATRIX.md) for the full area-by-area status and [KNOWN_ISSUES.md](KNOWN_ISSUES.md) for reproduced bugs. The following gaps compare the requested target platform with the audited local system; percentages are intentionally omitted because the target has no agreed denominator.

## Highest-value independent validation next

1. Reproduce the mobile Tree Diameter and Dice Combinations overflow on a 390px viewport and inspect affected controls.
2. Build a teaching-step prototype that groups Case B's 29 events into the four meaningful increases plus setup/result; assess comprehension with users.
3. Define event-specific schemas and test invalid status/collection/heap payloads through `createEvents()` and `reduceEvent()`.
4. Test restricted interpreter conformance for scope, const redeclaration, side-effecting indices, and worst-case responsiveness; keep full-language execution off until isolation exists.
5. Evaluate whether the five flagged dependency advisories are reachable in the deployed build, then validate a reviewed upgrade.
6. Exercise a real local and a real HTTPS compatible model endpoint, including CORS, timeout, malformed response, and secret handling.
